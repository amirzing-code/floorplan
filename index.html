Underlay

Keyboard shortcuts
  • Click a tool = use once · double-click = lock tool
  • Drag doors / openings / windows straight onto a wall
  • V Select · W Wall · R Room
  • D Door · N Window · M Dimension
  • While drawing a wall: type a length (e.g. 3.5, 350cm, 12'6") + Enter
  • Polygon room: click corners · click the first corner / Enter / double-click to close
  • Auto room: click inside an area enclosed by walls
  • Shift toggle ortho · Alt no snapping
  • Ctrl+P print / save PDF to scale with title block
  • Q rotate 90° · Del delete · Ctrl+D duplicate
  • Ctrl+C / Ctrl+X / Ctrl+V copy, cut, paste (works across sheets)
  • Ctrl+G group · Ctrl+Shift+G ungroup · double-click = select one item in a group
  • Ctrl+F search tools & furniture · Enter = use first match
  • Sheet tabs: double-click = rename · right-click / ▾ = duplicate, copy items to another sheet, reorder, delete
  • Drag empty space = box select · Shift+click = add/remove · Ctrl+A select all
  • Arrow keys = nudge selection (Shift = ×10)
  • Mouse wheel = zoom · right-drag / Space + drag = pan
  • Esc / double-click finishes a wall · Esc again = back to Select

Print / Save as PDF

Title block

In the browser's print window choose Save as PDF (or a printer) and keep scale at 100% / Default so the drawing stays true to scale.

Quantities (BQ)

Heights in . Wall finish = room perimeter × ceiling height, minus the doors and windows on that room's walls. Skirting = room perimeter minus door widths.
